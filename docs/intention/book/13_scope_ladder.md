# 13 — Scope ladder

## Must ship (MVP)
Stages S2–S8 as re-expressed in this book: capture hook + watcher; sessions, items, photos with
review, undo, order, Original/Adjusted; unassigned, move, copy, import; attribute schema, presets,
form with provenance UI; local export; Shopify adapter with the capability set in chapter 09;
publish runs with resume and retry; notifications; health; Tauri sidecar spike and packaged app
(ad-hoc signed); settings screen.

## Only if cheap
Capture trigger from the UI (`capture` command). Rating display (read-only). Phone remote
**layout** once a design exists; the transport already supports it. Dark mode (tokens exist).

## Explicitly deferred (non-goals for the MVP)
The AI research agent and description writing (chapter 08 ships its data model and UI states).
Second integration or second imaging provider. Plugin system. Licensing, subscriptions,
auto-update, notarised installer. Multi-user, cloud, remote access beyond the LAN. Catalog
documents. Video. Theme work on the customer's shop.
