# P44 capture ledger: projection r0

The capture-ledger plan is close, but it cannot go to the implementer yet. One rule copied from the book would file photos into the wrong session as soon as the camera's file counter comes round again, which happens every 9,999 shots. That needs your yes or no (card 1 below), unless the orchestrator decides the book already answers it. Separately, about twenty plan-level gaps need a paragraph each from the planner before the prompt is compiled. Three of them could quietly lose or misfile a photo: a staging file the camera sends again after an error, two ledger workers running during a settings save, and the multi-file count contradicting the plan's own rule. The rest are fixture, wiring and citation fixes that need nothing from you.

## ⚠ OWNER DECISIONS REQUIRED (1)

**Card 1: Matching a new photo to an old one with the same name**
- **Question:** Once the camera's file counter comes round again, should a new photo still be matched to an old photo that has the same name?
- **Story:** The camera numbers files DSC00001 to DSC09999 and then starts again. At a few thousand shots a day, that takes under a week. On Friday you shoot a chair and DSC01234.ARW arrives. The rule as written finds Monday's DSC01234, so the chair photo is filed into Monday's lamp session, which may already be published and now shows as changed. Friday's shutter press is still listed as waiting for its file, so the next photo shifts too, and "photos taken but not received" fires.
- **Branches:** *Match by name only for an identical copy, and by RAW+JPEG stem only within 5 minutes* → every photo lands in the session that was open when it was shot. *Keep the rule as written* → after the first wrap, photos keep going to old sessions.
- **Recommendation:** The first branch. It is what the chapter already promises: "every photo lands in the session that was open when the shutter fired".
- **On silence:** The gate holds and P44's implementer prompt is not compiled.
- **Trace:** 10E MC-33 R-I26 rules (1)–(2), R-I27, M38. P44 contract line 70, rows C2(c), C3(a)–(d).

*Routing note for the orchestrator (technical):* under flow §6 you may answer this from the book's §What the photographer gets and record it as an R-I26 clarification. If so, the card is closed by that record. Ledger row L1.
