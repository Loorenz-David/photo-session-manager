# Projection — P45_sidecar_and_protocol, round 0

P45 can be built: the camera helper copies cleanly and builds on this Mac both without and with Sony's kit. I tried both builds in a scratch folder outside the repository. But the plan needs about a dozen paragraph-sized corrections before the implementer starts. Three of the camera-helper changes are aimed at the wrong place in the lab's code: the "connection ready" report, the card-only write at quit, and the "file still downloading" guard. Built as written, each one would silently do nothing, and no test runs them before the owner's hardware day. Four of the planned tests could not pass as written either: the C++ test count, the start-up line the fake helper prints, a rejected-command script the real helper could never produce, and a field name the real helper never sends. Nothing needs the owner personally. The orchestrator folds the amendments below into the plan, and the implementer prompt compiles after that.
