# Projection of R8_research_real_adapters (round 0, attempt 2)

The amended R8 plan is close, but it still needs a short round of plan edits before the implementer starts. The most important problem: the plan says two opposite things about a listing site that cannot be reached. One paragraph says "could not be read, the run goes on", while a task and a test row say "hold the whole run as offline". Following the row would let one dead shop website stall research. The second problem: a research key you save while the app is running would never reach the new adapters, because the app does not rebuild them when a key is saved. The plan offers that rebuild as an option, but it does not exist. Nothing needs you personally: every point can be settled from the book and the orchestrator's earlier decisions, so the orchestrator applies the amendments and starts the build.
