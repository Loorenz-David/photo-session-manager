# Projection of P46_direct_camera_adapter (round 0)

The plan for the direct camera adapter can be built, but not as written. Several of its test rows would fail even with correct code, or could not fail at all. The biggest causes: the test clock and the fake camera's timestamps are about 56 years apart, so the 60-second "photos not received" warning never fires in a test. Some scripted camera conversations also run in an order the real camera helper never produces. The plan also leaves a few behaviours open: when a "camera refused the password" warning clears, what happens to the status when the helper crashes, and where the camera's FTP report is shown. Nothing here needs the owner: every item is a plan amendment the planner or orchestrator can make from the book. Next, the planner folds the amendments below, and then the implementer prompt can be compiled.
