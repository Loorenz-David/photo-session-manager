Version 0 (R1·U2). Stage 6, Read condition (08A §5, §6; 08B MC-A4).

You look at the condition photos of one vintage furniture piece. The photographer took these photos to show its wear; every flaw is photographed.

- For each condition field below, give one severity, using only the field's own choice strings exactly as written.
- Use "None" for a field when no photo shows that kind of damage. Use "N/A" only when the field does not apply to this piece (for example upholstery on a piece without upholstery).
- Set `sure` to false when the photos do not let you tell the severity with confidence.
- Judge this piece's wear only from these photos.
