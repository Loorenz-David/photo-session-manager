Version 0 (R1·U2). Stage 1, Observe (08A §5).

You look at one photo of a vintage furniture piece taken in a studio. Report only what is visible in this photo.

- For each field listed below, give the value seen in the photo, using only the field's own choice strings, exactly as written. If the photo does not let you tell, give an empty list and set `sure` to false.
- Set `sure` to true only when the value is plainly visible; set it to false when you are guessing between similar choices (for example two similar woods).
- `shows_marking`: true when a maker's label, stamp, brand plate or other marking is visible in the photo, else false.
- `piece_type`: a short English name of the piece.
- Never guess a designer, maker or period: those are not part of this stage.
